# 구현 로드맵

## 1단계: 현재 MVP 보강

- 문서 선택 버튼으로 PDF, TXT, MD 파일을 연결합니다.
- 사용자가 "요약해줘"라고 입력하면 선택된 문서를 요약합니다.
- Ollama가 실행 중이면 일반 질문을 로컬 AI 모델로 보냅니다.
- Ollama가 꺼져 있으면 기존 fallback 메시지를 보여줍니다.
- 사이트 열기 기능은 구글, 네이버, 유튜브, 깃허브를 우선 지원합니다.

## 2단계: 학습하기 좋은 코드 만들기

- `core`, `services`, `ui`로 역할을 분리합니다.
- 기존 파일은 호환 래퍼로 남겨 import가 깨지지 않게 합니다.
- 기능별 테스트를 추가합니다.
- 문서화 파일을 `docs/`에 둡니다.

## 3단계: 다음 구현 후보

- 문서 내용을 LLM에 넘겨 진짜 요약을 만들기
- 대화 기록 저장
- 최근 사용 문서 목록
- 모델 선택 UI
- 음성 인식 입력
- PPT 문서 요약
- 오류 메시지 개선

## 추천 작업 순서

1. Ollama 설치 후 `qwen3:4b` 실행
2. 앱에서 일반 질문 답변 확인
3. 문서 선택 후 요약 명령 확인
4. 대화 기록 저장 기능 추가
5. 모델 선택 UI 추가
