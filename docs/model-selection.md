# AI 모델 선정

## 추천 결론

이 프로젝트의 1차 추천 모델은 `qwen3:4b`입니다.

이유는 다음과 같습니다.

- 무료 로컬 실행이 가능합니다.
- Ollama로 Windows에서 설치와 실행이 쉽습니다.
- 한국어 질의응답과 일반 작업 보조에 무난합니다.
- 작은 MVP 앱에서 속도와 품질의 균형이 좋습니다.

## 설치 명령

```powershell
ollama pull qwen3:4b
ollama run qwen3:4b
```

DeskMate AI는 기본값으로 `qwen3:4b`를 바라보게 설정했습니다.

다른 모델을 쓰고 싶으면 PowerShell에서 환경 변수를 바꾸면 됩니다.

```powershell
$env:DESKMATE_OLLAMA_MODEL="qwen3:8b"
deskmate-ai
```

## 후보 비교

| 모델 | 추천 상황 | 장점 | 주의점 |
| --- | --- | --- | --- |
| `qwen3:4b` | 기본 추천 | 가볍고 한국어/일반 답변 균형이 좋음 | 고난도 추론은 약할 수 있음 |
| `qwen3:8b` | RAM 여유가 있을 때 | 답변 품질이 더 안정적 | 4B보다 느림 |
| `qwen3-coder:30b` | 코딩 보조 중심 | 코드 이해와 생성에 강함 | 메모리 요구량이 큼 |
| `llama3.2:3b` | 매우 가볍게 돌릴 때 | 빠르고 부담이 작음 | 한국어와 복잡한 답변 품질은 제한적 |
| `gemma3:4b` | 대안 모델 테스트 | 가벼운 로컬 실험에 좋음 | 프로젝트 기본 모델로는 Qwen을 우선 추천 |

## 나중에 바꿀 수 있는 기준

- 노트북 RAM이 16GB 이하이면 `qwen3:4b`부터 시작합니다.
- RAM이 32GB 이상이면 `qwen3:8b`를 테스트합니다.
- 코딩 답변 품질이 중요해지면 `qwen3-coder` 계열을 별도 옵션으로 둡니다.
- 앱 응답 속도가 중요하면 더 작은 모델을 선택합니다.
